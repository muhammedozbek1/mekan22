# Mekan 22

Edirne merkez fast-food & döner web uygulaması (React + Vite + Tailwind CSS).

## Çalıştırma

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Özellikler
- Mobil-öncelikli, responsive tasarım
- Canlı açık/kapalı durum rozeti (08:00 - 00:00)
- İnteraktif menü ve sepet sistemi
- WhatsApp ile sipariş (otomatik mesaj oluşturma)
- Trendyol Yemek, Yemeksepeti, GetirYemek linkleri
- Google Maps konum ve yol tarifi
